# Agenda da Turma — BR01/2026

Protótipo responsivo de uma agenda de turma em HTML, CSS e JavaScript puro.

## Como abrir no Windows
1. Extraia o ZIP.
2. Abra a pasta `agenda-da-turma`.
3. Dê dois cliques em `index.html` para abrir no navegador.

## Como publicar no GitHub Pages
1. Crie uma conta em https://github.com/signup.
2. Crie um repositório chamado `agenda-da-turma` e deixe-o público se quiser publicar pelo GitHub Pages.
3. Envie `index.html` e `README.md` para o repositório.
4. Abra **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e a pasta `/ (root)`, e salve.
6. Aguarde a publicação e abra o endereço que o GitHub Pages mostrar.

## Observação
Este projeto é uma recriação inicial baseada nas informações disponíveis publicamente no link de referência, não uma cópia do código original do Emergent. Confira datas, textos e regras com a coordenação antes de usar oficialmente. Não contém backend, login ou banco de dados.
